# Polaris Web Components MCP

MCP server (stdio, `src/index.ts`) that serves Shopify Polaris Web Component docs to AI assistants. Published to npm as `polaris-web-components-mcp`; the `bin` is the committed `dist/index.js`, so run `bun run build` and commit `dist/` after a source change.

- `bun run scrape` re-fetches the raw markdown from `https://shopify.dev/docs/api/app-home/polaris-web-components/{category}/{component}.md` for the components in `src/components.ts` and the patterns in `src/patterns.ts`. New Shopify components must be added to those lists first.
- `src/data/*.json` is generated by the scraper; do not edit it by hand. The markdown is stored unparsed; only icon type unions move to `icons.json`, replaced by a reference to the `search_icons` tool.
